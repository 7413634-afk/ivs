# ІВС температурного поля печі полімеризації порошкової фарби

12 каналів (П1–П9 — повітря, Лист / Труба / Опора — метал), термопари K класу 1,
12 × Adafruit 3263 (MAX31856), ESP32, USB. Поки що працює повна симуляція.
Архітектура дозволяє перейти на реальну ESP32 без змін розрахункової частини.

## Запуск

```bash
pip install -r requirements.txt
python main.py                     # інтерфейс (Windows: Запуск.bat)
python eksperyment.py              # серія: калібрування, бюджет U, порожня камера, 3 цикли з виробами
python doslidzhennia.py            # уставки 200/210/220 °C, вибір режиму, results_for_diploma.md
python -m unittest discover -s tests -v
```

## Структура

| Файл | Призначення |
|---|---|
| `konfig.py` | канали, CS-піни, режим фарби, шляхи `sim` / `real` |
| `model_pechi.py` | фізична модель печі (ТЕНи, повітря, обшивка, ізоляція, витяжка, двері, партія) і трьох виробів |
| `termopara.py` | НСХ типу K (NIST ITS-90), пряма й обернена |
| `vymiriuvannia.py` | модель каналу: відхилення ТП, дрейф, MAX31856 (підсилення, зміщення, шум, квантування), холодний спай, випромінювання, контакт, інерція |
| `dzherela.py` | `SimSource` і `Esp32Source`, однаковий формат рядків `Row` |
| `kalibrovka.py` | калібрування в точках 50…250 °C, МНК `T' = a + b·T`, імпорт реального CSV |
| `neviznachenist.py` | бюджет невизначеності окремо для повітря і металу, `U = 2·u_c`, поріг `T_фарби + U_метал` |
| `analiz.py` | Δt, σ_t, прогрів, відновлення, досягнення порогу, максимальна неперервна витримка, перевірка покриття U |
| `zvit.py`, `eksperyment.py` | CSV, PNG, `pidsumok.md` |
| `doslidzhennia.py`, `dyplom.py` | порівняння уставок, вікно тривалості циклу, чутливість, `results_for_diploma.md` |
| `esp32/ivs_max31856/` | прошивка ESP32 (Arduino) |

## Дані

- `data/sim/`, `zvit/sim/`, `kalibrovka_sim.json` — симуляція;
- `data/real/`, `zvit/real/`, `kalibrovka_real.json` — реальні вимірювання;
- старі файли в корені `data/` і `zvit/` залишені без змін.

Симуляція відтворювана: датчики задає `HW_SEED = 2026`, кожен цикл має свій seed (`eksperyment.py`).
Для симуляції поруч із показами пишеться `*_true.csv` з дійсними температурами моделі. За ним
перевіряється, чи потрапляє похибка в U.

## Реальна ESP32

1. Прошити `esp32/ivs_max31856/ivs_max31856.ino` (бібліотека Adafruit MAX31856).
2. У `main.py` вибрати джерело «ESP32 (USB)» і вказати COM-порт.
3. Калібрування: CSV `T_еталон;П1;…;Опора` (один рядок на відлік, по 50…250 °C) → кнопка «Калібрування».
   Після цього U і поріг витримки рахуються з реальних даних.
